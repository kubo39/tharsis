# UART

Hello, World!を出力するためにUARTに進もう。

QEMU virtのUARTはns16550a互換の制御レジスタ群で、メモリアドレス `0x10000000` から `0x100` の範囲でマップされている([参考: Qemu v8.2のコード](https://github.com/qemu/qemu/blob/v8.2.2/hw/riscv/virt.c#L97))

このアドレスに直接書き込めばいいのだが、ただのstore(`*x = 42;`のような)にしてしまうと最適化で消されたり複数のstoreをひとつにまとめられてしまったりするので、`core.volatile` の `volatileStore` を使う。

```d
void writeByte(ulong reg, ubyte c)
{
    volatileStore(cast(ubyte*) (UART0 + reg), c);
}
```

## noreturn

なお余談として、kmain関数は最後に無限ループで `wfi` 命令で割り込み待ちを行っている。

```d
    while (true)
    {
        __asm("wfi", "");
    }
```

この関数は `noreturn` を使って戻ってこない関数を表していて、関数の実行フローに最後は無限ループを使うか `assert(0)` を使うかする必要がある。

`--checkaction=halt` で `assert(0)` を使う場合、LLVMのintrinsic `llvm.trap` が使われ、最終的には `unimp` (不正命令)に落ちる。
今は `--checkaction=C` にして `assert` の失敗時に呼ばれる `__assert` を自前で実装している(メッセージとbacktraceを出して `wfi` で止まる)ので、`noreturn` な関数の最後は無限ループで統一している。
