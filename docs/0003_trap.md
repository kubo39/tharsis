# トラップの処理(例外・割り込み)

トラップについてやる前に、いちおうトラップと例外・割り込みの関係を書いておこう。

トラップといったときは例外と割り込みの総称と考えればまあよい。
例外と割り込みの違いについては、

- 例外: 実行中の命令によって起きる同期的なもの(不正命令 `unimp` とか)
- 割り込み: 命令に関係なく非同期に起きる(タイマーとか)

って感じで分類できる。

RISC-Vは(Directモードでは)例外と割り込みを共通のトラップハンドラで扱い、その中で `scause` の最上位ビットでどちらが来たか区別している。

## 方式

トラップについては、ページテーブルの扱いによって実装がわかれる:

1. カーネルとプロセスでページテーブルを共有する
  - Linux, FreeBSD, OS in 1,000 Linesなど、基本的にはこれ
  - `stvec` に登録するハンドラをカーネルとユーザランドで分けない
  - カーネルを全プロセスのページテーブルにマップする前提
  - トラップがカーネルで発生したかユーザランドで発生したかは `sscratch` レジスタをみて判定する
2. カーネルとユーザランドでページテーブルを分離する
  - xv6-riscvで使われてる方式
  - カーネルとユーザランドでページテーブルを分けており、両方のページテーブルにマップしたtrampolineページ上で `satp` を切り替える
  - `stvec` で登録するトラップハンドラはカーネルとユーザランドを行き来するたびに書き換える
    - `satp` を切り替えるたびに `sfence.vma` でTLBフラッシュ(TLBの中身を無効にする)ので当然実行コストはかかる

今回の実装では1を選択するのだが、ここでちょっとだけTLBについて補足しておこう。

TLBというのは仮想アドレスから物理アドレスへの変換結果をキャッシュしておく機構だ。
RISC-Vでは、satpを書き換えた場合やページテーブルの中身を直接書き換えた場合であってもTLBを勝手に捨てることはない。なのでxv6-riscv方式だとトラップが発生するたびに明示的に消してやる必要がある。
(注: ページテーブルを直接書き換えた場合はともかく、x86の場合はページテーブルの切り替えを行う場合、つまり`CR3`(`satp`相当)に書き込むとグローバルでないエントリにかんしては自動でフラッシュされる)

## ハンドラの登録

さきほどもちょろっと出てきたが、一番最初にやることは `stvec` にハンドラのアドレスを登録することになる。

```d
    writeCsr!"stvec"(cast(ulong) &kernelEntry);
```

`stvec` の下位2ビットはモードを表すので、トラップハンドラは4バイト境界で配置されている必要がある。
ところがLDCは関数レベルでのアラインはできないので、リンカスクリプト側で配置を制御することにしよう(`+c`で圧縮命令をサポートしなければ4バイトアラインになるがいずれにしろ明示的にやったほうがよいだろう)。

リンカスクリプトは書き方に注意しよう。
リンカはリンカスクリプトに書かれた順にルールをみて最初に一致したルールに割り当てるので、さきに `.text.trap` を書いておかないと汎用パターンに引っかかってインプットセクションがまとめられてしまう。

```ld
    .text : {
        KEEP(*(.text.boot))
        . = ALIGN(4);
        KEEP(*(.text.trap))
        *(.text .text.*)
    }
```

```d
@section(".text.trap")
@naked void kernelEntry()
{
    __asm(`
        csrw sscratch, sp

        # スタックを16バイト境界にするために8 * 32にしてる
        addi sp, sp, -8 * 32
        sd ra,  8 * 0(sp)
        sd gp,  8 * 1(sp)
        sd tp,  8 * 2(sp)
        sd t0,  8 * 3(sp)
        sd t1,  8 * 4(sp)
        sd t2,  8 * 5(sp)
        sd t3,  8 * 6(sp)
        sd t4,  8 * 7(sp)
        sd t5,  8 * 8(sp)
        sd t6,  8 * 9(sp)
        sd a0,  8 * 10(sp)
        sd a1,  8 * 11(sp)
        sd a2,  8 * 12(sp)
        sd a3,  8 * 13(sp)
        sd a4,  8 * 14(sp)
        sd a5,  8 * 15(sp)
        sd a6,  8 * 16(sp)
        sd a7,  8 * 17(sp)
        sd s0,  8 * 18(sp)
        sd s1,  8 * 19(sp)
        sd s2,  8 * 20(sp)
        sd s3,  8 * 21(sp)
        sd s4,  8 * 22(sp)
        sd s5,  8 * 23(sp)
        sd s6,  8 * 24(sp)
        sd s7,  8 * 25(sp)
        sd s8,  8 * 26(sp)
        sd s9,  8 * 27(sp)
        sd s10, 8 * 28(sp)
        sd s11, 8 * 29(sp)

        csrr a0, sscratch
        sd a0, 8 * 30(sp)

        mv a0, sp
        call handleTrap

        ld ra,  8 * 0(sp)
        ld gp,  8 * 1(sp)
        ld tp,  8 * 2(sp)
        ld t0,  8 * 3(sp)
        ld t1,  8 * 4(sp)
        ld t2,  8 * 5(sp)
        ld t3,  8 * 6(sp)
        ld t4,  8 * 7(sp)
        ld t5,  8 * 8(sp)
        ld t6,  8 * 9(sp)
        ld a0,  8 * 10(sp)
        ld a1,  8 * 11(sp)
        ld a2,  8 * 12(sp)
        ld a3,  8 * 13(sp)
        ld a4,  8 * 14(sp)
        ld a5,  8 * 15(sp)
        ld a6,  8 * 16(sp)
        ld a7,  8 * 17(sp)
        ld s0,  8 * 18(sp)
        ld s1,  8 * 19(sp)
        ld s2,  8 * 20(sp)
        ld s3,  8 * 21(sp)
        ld s4,  8 * 22(sp)
        ld s5,  8 * 23(sp)
        ld s6,  8 * 24(sp)
        ld s7,  8 * 25(sp)
        ld s8,  8 * 26(sp)
        ld s9,  8 * 27(sp)
        ld s10, 8 * 28(sp)
        ld s11, 8 * 29(sp)
        ld sp,  8 * 30(sp)
        sret
    `, "");
}
```
