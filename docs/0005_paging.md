# ページング

## ページングとは

ページングとは、かんたんにいうと仮想アドレスを物理アドレスに変換する仕組みのことをいう。
ページングを使うと、プロセスごとにアドレス空間を分離できる。また、ページテーブルの各エントリに権限を持たせられるので、ページごとに権限(Read/Write/Execute)を設定できる。

## RISC-Vにおけるページング手法

RISC-Vにはいくつかページング方式があるが、今回はRISC-V 64bitの中でもっともシンプルなSv39(Supervisor-mode virtual memory, 39-bit)方式で実装を進める。
これは「Supervisorモードで使う、仮想アドレスが39bit(つまり512GiB)の方式」なのだが、以下のような仕組みとなっている。

- 仮想アドレスの内訳: 39bit = 9+9+9+12
  - 上位の9bit x 3は3段のページテーブルそれぞれの番号(0~511)
  - 下位の12bitは4KiBページの中の位置(オフセット)
  - 2^39 = 512GiBの仮想アドレス空間
- xv6-riscvやLinuxのrv64でも使われている方式
  - アドレス空間をもっと使える方式はあるがページテーブルの段数が小さいほどアドレス変換は高速になり、ページテーブル用のメモリも小さくなる
