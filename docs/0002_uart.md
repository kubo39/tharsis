## noreturn

なお余談として、kmain関数は最後に無限ループで `wfi` 命令で割り込み待ちを行っている。

```d
    while (true)
    {
        __asm("wfi", "");
    }
```

この関数は `noreturn` を使って戻ってこない関数を表していて、関数の実行フローに最後は無限ループを使うか `assert(0)` を使うかする必要がある。

`--checkaction=halt` で `assert(0)` を使う場合、LLVMのintrinsic `llvm.trap` が使われ、最終的には `unimp` (不正命令)に落ちる。
こちらを使うのもありだが、将来的にassert関数を実装する余地を残すために今のところは無限ループで統一している。
